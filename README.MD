# Evaluación 2 - Software de Geolocalización y Control de Versiones

## Descripción
Este proyecto contiene un script en Python desarrollado en la Máquina Virtual DEVASC para consumir la API de GraphHopper. Permite calcular rutas, tiempos estimados, distancias y la narrativa paso a paso en español.

## Requisitos
* Python 3.8+
* Librería `requests` (`pip install requests`)
* Token / API Key de GraphHopper

## Instrucciones de Ejecución
1. Clonar o descargar este repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar el script con el siguiente comando:
   ```bash
   python3 EVALUACION2.py
